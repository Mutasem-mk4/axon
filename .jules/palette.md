## 2025-06-04 - Tabwriter Alignment with ANSI Colors
**Learning:** Using `text/tabwriter` for aligned console output breaks column width calculation when ANSI escape sequences (like colors or bold text) are added because the unrendered escape bytes are counted towards the cell width. To fix this, `tabwriter.StripEscape` must be used during initialization and all ANSI escape codes must be wrapped in `\xff` bytes so the tabwriter knows to exclude them from the layout calculation. Be careful: writing strings containing `\xff` directly to an `io.Writer` (instead of through `tabwriter`) will result in literal `\xff` characters in the output.
**Action:** Always enable `tabwriter.StripEscape` and wrap ANSI codes in `\xff` markers when formatting colored text into tabwriter columns. Keep separated raw escape codes for printing strings directly to the output stream outside of the tabwriter.
