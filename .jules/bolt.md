## 2026-05-27 - Optimize correlation assignment loop
**Learning:** In Go, iterating over slices of values (like `compact []CompactFinding`) using the traditional `for _, item := range compact` copies the entire struct by value into the `item` variable on each iteration. Since the dataset in `BenchmarkServiceRunStable100000` is huge, this copy overhead severely hits memory and CPU. Iterating via `for i := range compact` and using a pointer reference `item := &compact[i]` bypasses value copying and vastly speeds up execution times. Furthermore, setting the `Representative` value inside the struct creation avoids an unnecessary loop assignment.
**Action:** Always prefer index-based iteration `for i := range slice` and getting the value with pointers when looping over slices of large structs, particularly inside high-volume data ingestion or correlation loops.
